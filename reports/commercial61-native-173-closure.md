cleanup of 20 mounts, backing-file and outer-filesystem flushes, and no seed reset.

verifier, or a documented legitimate package provision path. PCSettings is a
different bundle, not a repair of Settings. No package substitution, signature

## USB observation

Four sanitized sysfs samples at 8738, 32138, 53784 and 74390 monotonic milliseconds
contain no VID/PID outside the previous baseline. The later samples contain six
root hubs, Huawei detachable 12d1:10b8 and Realtek Ethernet 0bda:8153.
The current Ubuntu lsusb check also lists only these eight devices.

These are kernel/backend observations, not original HarmonyOS USB-service/UI
acceptance. Continuous hotplug capture was not verified, so a transient insertion
between samples cannot be excluded. No USB serial strings were exported by the
new analysis. Ask which kind of newly inserted device the user expects before
attributing the existing Ethernet adapter to this insertion.
